# Replies: sign-in hangs (Google or Apple)

> For support: pick the variant matching the cause you found in [../problems/sign-in-hangs-google-apple.md](../problems/sign-in-hangs-google-apple.md). Each section is a ready-to-send email body.

## try-again-stay-in-browser

Hi [first name],

Thanks for writing. Sorry the sign-in stalled. When the sign-in window closes early, or the connection is weak, the app can be left waiting.

Please try this:

1. Tap the sign-in button again.
2. Stay in the sign-in window until it takes you back to the app. Please don't switch to other apps.
3. If you're on a weak connection, move to a steadier one first.

If it still won't work, tap "Continue with Email" instead. It doesn't need a browser. If your Google or Apple account uses the same address, it will lead to the same records. Apple's Hide My Email is the exception: use the Apple button.

Warmly,
RecoverySky Support

## allow-the-ios-prompt

Hi [first name],

Thanks for getting in touch. On iPhone, iOS can show its own "Sign In" message while you sign in. It comes from your phone, not from our app.

Please try again and, when that message appears, go through it rather than cancelling it. Cancelling stops the sign-in, which is why it looked like nothing happened.

Then stay in the sign-in window until it returns you to the app. If it still stalls, you can use "Continue with Email" and a code instead. Reply if you need more help.

Warmly,
RecoverySky Support
