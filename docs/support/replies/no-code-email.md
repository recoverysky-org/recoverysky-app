# Replies: no code email

> For support: pick the variant matching the cause you found in [../problems/no-code-email.md](../problems/no-code-email.md). Each section is a ready-to-send email body.

## A2-A6-wait-and-resend-once

Hi [first name],

Thanks for your patience. Sometimes the code email is slow, and asking for several codes in a row can make it slower. The app also limits how often a code can be sent.

Please try this:

1. Wait a few minutes.
2. Tap "Resend code" just once.
3. Use only the newest email when it arrives. Older codes stop working.

Please check your spam folder as well. If nothing has come after about ten minutes, reply and we'll look into it.

Warmly,
RecoverySky Support

## A3-B2-cannot-deliver

Hi [first name],

Thank you for your message. It looks like we can't deliver email to [the address you used], so the code can't reach you. This can happen when a mail provider refuses messages, or when an address was typed with a small mistake.

You have a few options:

1. Check the address for typos. If you find one, go back in the app and enter the correct one.
2. Try a different email address that you can read.
3. On the sign-in screen, choose "Continue with Google" or "Continue with Apple" if you use one of those. If you have a password, "Can't get a code? Sign in with your password" is also there.

Reply if none of these work and we'll find another way.

Warmly,
RecoverySky Support

## A4-connection

Hi [first name],

Thanks for getting in touch. The "We couldn't reach the sign-in service" message usually means the connection was too slow or dropped, and the email may already be on its way.

Please try this:

1. Check your inbox and spam folder for a new email from us, and use the newest one.
2. If nothing has come, switch to a steadier connection (mobile data instead of Wi-Fi, or the other way round) and turn off any VPN.
3. Try again.

Making sure you have the latest version of the app from the store helps too. Reply if it still doesn't work.

Warmly,
RecoverySky Support
