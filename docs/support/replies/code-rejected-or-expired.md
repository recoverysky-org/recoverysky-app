# Replies: code rejected or expired

> For support: pick the variant matching the cause you found in [../problems/code-rejected-or-expired.md](../problems/code-rejected-or-expired.md). Each section is a ready-to-send email body.

## wrong-or-old-code

Hi [first name],

Sorry about the trouble with your code. Two things cause this most often: a typo in one of the six digits, or using a code from an earlier email. Only the newest code works, so each time you ask for a new one, the older emails stop working.

Please try this:

1. Open the app and ask for one new code. Tap it once only.
2. Wait for the email to arrive.
3. Open the newest email from us and type the six digits carefully.

If it still doesn't work, reply and tell us which screen you were on and what message it showed. Please don't send us the code itself.

Warmly,
RecoverySky Support

## expired

Hi [first name],

Thanks for getting in touch. The message you saw means the code ran out of time. Codes only work for a short while, so if the email took a few minutes to reach you, it may already have expired.

Here is what to do:

1. In the app, ask for a new code. On the sign-in screen the button is "Resend code". On the email check screen it is "Send code".
2. Open the newest email as soon as it arrives.
3. Type the six digits straight away.

If the email is slow to arrive, check your spam folder too. Reply if it keeps happening and we'll look into it.

Warmly,
RecoverySky Support

## too-many-tries

Hi [first name],

Sorry for the hassle. After several wrong codes in a row, the app pauses and asks you to wait. That is a safety step to protect your account, and nothing is wrong with your account.

Please wait a few minutes. Then ask for a fresh code (tap once) and use the newest email we send you. Take your time typing the six digits.

If you still can't get in after that, reply with the address you're signing in with and the time you tried, and we'll take a closer look.

Warmly,
RecoverySky Support

## too-many-requests

Hi [first name],

Thanks for your patience. The app limits how many codes can be requested in a short time, and it looks like you reached that limit. That keeps your account safe, and it doesn't mean anything is wrong.

Please wait a few minutes and then tap once to ask for a new code. Use only the newest email when it comes. Earlier ones won't work.

If you're still stuck after waiting, reply and let us know. We're happy to help.
