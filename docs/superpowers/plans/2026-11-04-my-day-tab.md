# The My Day tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sixth bottom tab, **My Day**, for premium accounts, hosting `@daily-dash/my-day`'s screens over the person's existing Auth0 session, in the app's light or dark scheme and tint, with the Dash's photo and glass, every word through i18n, and a store build on a branch.

**Architecture:** Three vendored packages (`@daily-dash/sdk`, `client`, `my-day`) sit beside `@recoverysky-org/common`. A `DailyDashProvider` in `app.tsx` mounts the client's `ClientProvider` only while the tab's gate holds (signed in, not a guest, premium, a configured API URL, not web) over one session object built at boot; a driver signs that session in with the tokens the app already holds and never signs it out. The tab is a native stack whose every screen is wrapped in `MyDayProvider` (theme, copy, surfaces, navigation) and a `MyDayGate` that draws the client's non-ready states. Pure decisions live in `*Logic.ts` modules under vitest; I/O in thin adapters verified on a device.

**Tech Stack:** Expo 54 / React Native 0.81.5 / React 19.1, React Navigation 7 (bottom tabs + native stack), MobX-State-Tree, i18next, expo-blur 15.0.x (new, native), `@tanstack/react-query` 5.104 (new, peer of the packages), `@expo-google-fonts/inter` and `playfair-display` 0.4.x (new), vitest for pure modules.

**Spec:** `docs/superpowers/specs/2026-10-25-my-day-tab-design.md` (§4 the host, §7 the release; §5 is the Daily Dash hand-off, planned in `../../jenova-marie/the-daily-dash-app/docs/superpowers/plans/2026-11-04-my-day-recoverysky-host.md`, which lands **first**). Executors read both.

## Review Focus

1. **A sign-out keeps My Day's data.** No code path may reach the client's wiping sign-out from logout. Pinned in Task 12: `dailyDashPolicy.test.ts` scans `app/` for `signOut(` on a Daily Dash session and allows exactly one call, `signOut("reset_local_data")` in `SettingsScreen.tsx`; and in Task 8: `dailyDashDriverLogic.test.ts` "the gate releasing is never a sign-out".
2. **A free account never gets a Daily Dash account minted.** Pinned in Task 8: `decideDailyDashAction` with `gateHolds: false` is `"none"` for every status.
3. **A cold start that restored no ID token.** The adapter renews once, then gives up with `unauthorized`, and never loops. Pinned in Task 6: `decideDailyDashSignIn` "renew once, then unauthorized".
4. **Android below 12 must not get the Dimezis blur.** Pinned in Task 4: `decideAndroidBlurMethod` at versions 30, 31, 34 and on iOS.
5. **A word My Day adds that `en.ts` lacks.** Pinned in Task 5: the parity test walks every leaf of the package's `defaultMyDayCopy` and fails on a missing key, a differing English string, or a function leaf with no sample arguments.

## Where this plan departs from the spec, and why

- **§4.2 "mounts once" is one session object, not one element.** `getDailyDashSession()` builds the session once; the `ClientProvider` element mounts while the gate holds and unmounts when it releases (§4.4: nothing runs for the Daily Dash account while signed out). `session.start()` is idempotent, so a remount costs a layer open, not a second restore.
- **One `MyDayProvider` per screen, not one around the stack.** The adapter needs the stack's own `navigation` prop (so `back()` pops the stack and `go()` stays inside it); a provider above the navigator has no such prop. `MyDayFrame` wraps each screen, as the package's `examples/react-navigation-host.tsx` does.
- **`reminders` is off.** The client has no `registerPushToken` today, so the Daily Dash API could not reach this app's push token; "Remind me later" would promise nothing. Queued in TODO.md (Task 15).
- **Thirteen photos, not eight.** `apps/app/assets/backgrounds/` holds 13 Pexels JPEGs (1.35 MB); all are copied.
- **A `my-day` manual area needs one line in the agent repo.** The manual's area list (`packages/types/src/manual.ts` `MANUAL_AREAS`) is closed; Task 14 adds `my-day` there before the pages validate.
- **Gate strings live under a `myDayGate` namespace**, separate from `myDay`, which mirrors the package's copy leaf for leaf.

**Interfaces:**
- Produces (pure; `MyDayTheme` imported as a type only):

  - `export function contrastRatio(a: string, b: string): number` — `(L1 + 0.05) / (L2 + 0.05)`, lighter over darker.
